# Vid Downloader

**Vid Downloader** adalah aplikasi desktop Windows yang dirancang khusus untuk mencari, memutar, dan mengunduh video maupun audio dari YouTube dan platform lainnya secara cepat, fleksibel, dan 100% aksesibel bagi pengguna tunanetra / pembaca layar (screen reader).

---

## Fitur Utama

- **Pencarian Cepat & Langsung:** Cari video cukup dengan mengetik judul lagu/video atau menempelkan URL YouTube.
- **Format & Kualitas Fleksibel:** Unduh dalam format Video (MP4) hingga resolusi 1080p, atau Audio (MP3) jernih hingga 320kbps.
- **Pemutar Bawaan (Preview):** Dengarkan atau tonton langsung video sebelum memutuskan untuk mengunduhnya.
- **Salin Tautan Mudah:** Dukungan tombol Aplikasi / klik kanan untuk menyalin URL ke clipboard seketika.
- **Aksesibilitas Penuh (Screen Reader Friendly):** Seluruh elemen, label, dan pintasan keyboard dirancang optimal untuk NVDA, JAWS, dan pembaca layar Windows lainnya.

---

## Pintasan Keyboard (Shortcut)

### Di Jendela Utama:
- **`Enter`** (di Kotak Pencarian): Menjalankan pencarian.
- **`Panah Bawah`** (dari Kotak Pencarian): Melompat ke daftar hasil pencarian.
- **`Panah Atas / Bawah`**: Menjelajahi daftar hasil pencarian.
- **`Enter`** (di Daftar): Memutar lagu/video secara langsung melalui pemutar bawaan.
- **`Tombol Aplikasi / Application Key`**: Membuka menu konteks untuk menyalin link video.

### Di Jendela Pemutar Media:
- **`Spasi`**: Jeda (*Pause*) / Lanjutkan (*Play*).
- **`Panah Atas / Bawah`**: Mengatur volume suara (naik/turun).
- **`Panah Kanan / Kiri`**: Maju / Mundur 5 detik.
- **`S / D / F`**: Mengatur kecepatan putar (0.5x lambat, 1.0x normal, 2.0x cepat).
- **`Escape`**: Menutup pemutar dan kembali ke menu pencarian.
